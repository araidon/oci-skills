# レイアウト規則

Oracle 公式の Landscape Sample に準拠した配置ルール。
`scripts/build_drawio.py` はこの規則どおりに座標を計算する。
手で XML を書く場合もこれに合わせること。

---

## 階層

Availability Domain (AD) の枠は描かない。サブネットは VCN 幅いっぱいに広げ、
役割ごとに縦に積む（Edge / App / Data）。

```
┌─ Region（実線グレー・白背景）────────────────────────────────┐
│                                                              │
│ [IGW]┌─ VCN（破線オレンジ）──────────────┐[SGW]   [Object     │
│ [NAT]│                                    │        Storage]   │
│ [DRG]│  ┌─ Edge Subnet ───────────────┐   │        [Vault]    │
│      │  │  [LB]  [Bastion]            │   │        [Logging]  │
│      │  └─────────────────────────────┘   │                   │
│      │  ┌─ App Subnet ────────────────┐   │                   │
│      │  │  [VM]  [VM]  [VM]           │   │                   │
│      │  └─────────────────────────────┘   │                   │
│      │  ┌─ Data Subnet ───────────────┐   │                   │
│      │  │  [ADB]                      │   │                   │
│      │  └─────────────────────────────┘   │                   │
│      └────────────────────────────────────┘                   │
└───────────────────────────────────────────────────────────────┘
```

## ゲートウェイの配置

ゲートウェイのアイコンは **VCN の枠線に跨がらせる**（アイコン中心を枠線に合わせる）。
`parent="vcn-1"` のまま、x をマイナスにする。

| ゲートウェイ | 位置 | VCN 相対座標 |
|---|---|---|
| Internet Gateway | VCN 左枠線 | `x=-30, y=80` |
| NAT Gateway | 左枠線（IGW の下） | `x=-30, y=200` |
| DRG | 左枠線（NAT の下） | `x=-30, y=320` |
| Service Gateway | VCN 右枠線 | `x=(VCN幅-30), y=80` |

縦の間隔は 120px。

---

## VCN の外に置くもの

VCN に属さないサービスは Region の内側・VCN の右に縦に並べる。

Object Storage / Vault / Autonomous Database（プライベートエンドポイント無し）/
OCIR / Streaming / Notifications / Queuing / IAM / Logging / Monitoring など。

オンプレミスやインターネットなど OCI の外にあるものは Region の外（左側）に置く。

## グリッド

| 項目 | 値 |
|---|---|
| アイコン | 60 × 60 px |
| アイコン中心間 | 160 px（アイコン60 + 余白100） |
| 行送り（折り返し時） | 110 px |
| 1行に並べる上限 | 5 個（超えたら折り返す） |
| コンテナ内側の余白 | 20 px |
| コンテナ上部のラベル余白 | 40 px |
| サブネット間の間隔 | 20 px |
| ラベル位置 | アイコンの下 |
| グリッドスナップ | 10 px |

## サイズの目安

1サブネット（アイコン1行）の高さ = 40（ラベル）+ 60（アイコン）+ 40（下余白）= **140px**

VCN 幅 = サブネット幅 + 40、最小 500px。

## 接続線

```
endArrow=none;startArrow=none;strokeColor=#000000;strokeWidth=1;edgeStyle=orthogonalEdgeStyle;
```

- 矢印は付けない（データフローの向きを主張しない）
- 直交ルーティング
- VCN / Subnet の枠線を跨いでよい
- `source` / `target` で要素同士を結ぶ（座標で線を引かない）
